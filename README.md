# COMPASSION WORLD Members

COMPASSION WORLDのポイントカード、会員QR、施設予約、モバイルオーダーを一つにまとめる会員向けWebアプリです。

## 主な機能

- ポイント残高・履歴
- 会員QR
- クーポン・会員ランク・お知らせ
- FEBBRAIOの予約・利用・精算状況
- Aozora Kitchenのモバイルオーダー
- 商品リクエスト

## 決済とポイント

- Stripeによるカード支払いの表示名は「スマート決済」に統一します。
- モバイルオーダーとスタジオ利用料は、現地決済・スマート決済のどちらでもポイント対象です。
- 住民登録プランの月額料金はポイント対象外です。
- ポイント残高の正本はスマレジとし、決済成功後の売上登録完了をもって付与します。
- 決済失敗では付与せず、取消・返金時は売上とポイントを連動して戻します。
- StripeイベントIDと決済IDを保存し、再送による二重売上・二重付与を防止します。
- `SMART_PAYMENT_ENABLED` は、Stripe決済作成・Webhook署名検証・スマレジ売上登録がすべて接続された環境だけで `true` にします。

## キッチン提供予定連携

- 商品選択中はキッチンの見積もりAPIから提供予定を取得します。
- 現地決済・スマート決済の完了時に確定予定を再計算します。
- 会員証、モバイルオーダー、セルフレジ、キッチンで同じ予定を使用し、取得できない場合は「提供予定：できあがり次第」と表示します。
- 公開環境にはキッチンと同じ `KITCHEN_API_TOKEN` を設定します。接続先を変更する場合だけ `KITCHEN_SCHEDULE_API_BASE_URL` を設定します。

## 開発

```bash
pnpm install
pnpm dev
pnpm test
```

通常の変更は作業用ブランチで行い、GitHub上の確認を経て `main` へ反映します。秘密情報はリポジトリへ保存せず、公開環境の環境変数で管理します。
