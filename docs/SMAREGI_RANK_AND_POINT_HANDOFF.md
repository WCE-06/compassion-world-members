# セルフレジプロジェクト引き継ぎ書：スマレジ年間利用額・会員ランク・ポイント連携

更新日：2026年8月23日

## 目的

スマレジを売上・ポイントの正本として維持しながら、会員証へ直近365日のお買い上げ金額、会員ランク、ランク還元率を反映します。スマレジ側の取得・集計・ポイント更新はセルフレジプロジェクトが担当し、会員証プロジェクトは同期結果の保存・ランク判定・表示を担当します。

## ランク条件

| ランク | 直近365日の対象利用額（税抜） | 還元率 |
|---|---:|---:|
| スタンダード | 0円 | 1% |
| ブロンズ | 30,000円 | 2% |
| シルバー | 60,000円 | 3% |
| ゴールド | 120,000円 | 5% |
| プラチナ | 180,000円 | 7% |
| ダイヤモンド | 300,000円 | 10% |

住民会員は利用額にかかわらずゴールド以上とします。利用額でプラチナ・ダイヤモンドへ昇格できます。

## セルフレジ側で行う作業

1. スマレジAPIから会員番号別に直近365日の売上を取得する。
2. 税抜・値引後・返品取消反映後のポイント対象利用額を集計する。
3. 初回は全会員を一括集計し、以降は毎日1回再集計する。管理画面から手動再実行も可能にする。
4. 100件以下に分割して会員証の同期APIへ送る。
5. 会計前に会員特典APIを呼び、現在のランク還元率を取得する。
6. 決済成功後に一度だけスマレジへポイントを付与する。月額住民登録料はポイント対象外とする。
7. 取消・返品時は対応するポイントを取り消す。

## 集計ルール

- 対象期間：実行時点から遡る365日
- 金額：税抜、値引後の実支払対象額
- ポイント利用分：新たなポイント付与対象から除外
- 取消・返品：減算
- 住民登録サブスク月額：対象外
- おもひで商店、Aozora Kitchen、モバイルオーダー、スタジオ利用：スマレジ売上として記録された対象取引を含む
- 一度スマレジ集計が届いた会員は、その集計値を正本とする。会員証内の注文記録と加算して二重計上しない

## 年間利用額同期API

`POST /api/v1/admin/smaregi-spend-sync`

認証ヘッダー：`x-compass-migration-key: （共有済みの移行キー）`

```json
{
  "rows": [
    {
      "memberCode": "A7K4P9X2M6",
      "qualifyingSpendExcludingTax": 125000,
      "periodStart": 1755907200000,
      "periodEnd": 1787443200000,
      "sourceRevision": "smaregi-20260823"
    }
  ]
}
```

- 会員番号は半角英数字10文字・大文字へ正規化する
- 金額は0以上の整数円
- 集計期間は360〜370日の範囲
- 最大100件／リクエスト
- 未登録会員は作成せず `MEMBER_NOT_FOUND` として返す
- 同じ会員への再送は上書きされるため冪等

## 会員特典取得API

`GET /api/v1/pos/member-benefit?memberCode=A7K4P9X2M6`

認証ヘッダー：`Authorization: Bearer （POS_API_TOKEN）`

主な応答：`rank`、`rankLabel`、`pointRatePercent`、`qualifyingSpend`、`amountToNextRank`、`membershipType`、`qualifyingSpendUpdatedAt`

集計未完了時は `qualifyingSpendSource: NOT_SYNCED` です。この場合、過去利用額を0円と決めつけてポイント付与せず、再同期または既定の安全な運用へ回してください。

## 障害・再発防止

- スマレジ取引IDを冪等性キーにし、二重ポイントを禁止する
- API失敗時に推測値を保存しない
- 同期件数、未登録件数、最終成功日時、失敗理由を記録する
- 合計額が前日から大幅減少した場合は自動反映せず警告する
- テスト会員で「購入・返品・ポイント利用・住民ゴールド下限」を確認してから全会員へ展開する
- 本番公開順は「会員証API公開 → 初回365日同期 → 金額確認 → セルフレジで還元率適用」です
